# Mapa Completo de Habilidades — Orquestrador Jurídico

## Como usar este mapa

Para cada demanda recebida, localizar a coluna "Frases típicas" e identificar a skill correspondente.
Priorizar a demanda **mais específica** quando houver sobreposição.

## Cenários Multi-skill (sequenciamento)

### Novo cliente em área regulada
1. `conflict-check` → verificar conflito
2. `onboarding-cliente` → kit de entrada
3. `analise-legislacao` → normas do setor
4. `precificacao-honorarios` → proposta comercial

### Ação judicial (do início ao fim)
1. `analise-risco-processual` → viabilidade
2. `pesquisa-jurisprudencia` → embasamento
3. `resumo-pecas` → estrutura da petição
4. `gestao-prazos` → mapeamento de datas

### Contrato novo (criação)
1. `gerador-minutas` → redigir minuta
2. `revisao-contratos` → revisar riscos
3. `lgpd-escritorio` → cláusula de dados se necessário

### Contrato recebido (análise)
1. `revisao-contratos` → análise de risco
2. `edicao-cirurgica` → ajustes cirúrgicos
3. `comunicados-clientes` → comunicar resultado ao cliente
