# Memória Institucional

Memória **de capacidade** do MF-AOS — decisões, padrões identificados e
registro de tipos de trabalho. É a versão mínima viável do Memory Engine
(`MF-OPERATIONS.md` §2) que pode viver em Git.

## O que vive aqui

| Arquivo | Conteúdo |
|---|---|
| `decision-log.md` | Decisões relevantes que não mereceram ADR formal |
| `registro-de-trabalho.md` | Contagem **anônima** de tipos de demanda atendida — insumo do MF Evolution Engine (`MF-OPERATIONS.md` §9) |

## O que NUNCA vive aqui

Dado real de cliente, caso, processo ou credencial (`SECURITY.md`). A memória
de **casos** (clientes, prazos, documentos) é o Memory Engine persistente do
roadmap T2 e viverá fora deste repositório Git.
